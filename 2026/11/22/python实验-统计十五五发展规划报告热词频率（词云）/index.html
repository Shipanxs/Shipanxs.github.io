python实验-统计十五五发展规划报告热词频率（词云）

2026-11-22
字数统计: 1.9k   |   阅读时长≈ 7 分钟

这次实验想验证一个直觉：一份政策文件里反复出现的词，能不能反映它真正关心的事。文本选了《中华人民共和国国民经济和社会发展第十五个五年规划纲要》全文（中国政府网 2026 年 3 月 13 日受权播发），完整走了一遍”抓取—清洗—分词—统计—词云”的流程，最后得到一张能直接看的热词图。

一、数据与工具

  • 文本：十五五规划纲要全文，清洗后正文 57,454 字（已剔除文首目录、表格图片与页脚导航）。
  • 环境：Python 3.13、jieba 0.42.1、wordcloud 1.9.6、matplotlib 3.11.2，Windows 11。
  • 产出：词频表（前 300 词，存 CSV）+ 词云图（前 160 词）。

二、处理流程

整个流程可以拆成四步：

  1. 抓取与清洗：下载页面后定位正文容器（class="pages_content"），去掉 script/style 与所有标签，反转义 HTML 实体，压缩空白；再把文首的目录整段切掉，避免 18 篇 62 章的标题被重复计数一次。
  2. 分词：jieba 精确模式。先把”中国式现代化””新质生产力””高质量发展””现代化产业体系””全国统一大市场””数字经济””一带一路”等短语加进自定义词典，否则它们会被切成”新质 / 生产力””中国式 / 现代化”这种碎片。
  3. 过滤：去掉单字、纯数字和标点；停用词分两类——一类是虚词（的、了、和、及、为、以……），另一类是政策文本里的”万能动词”（推进、加快、加强、坚持、建设、推动、完善、深化、健全、统筹……）。第二类不删，词云会被它们铺满，真正的主体词根本露不出来。
  4. 统计与可视化：Counter 计数后取前 160 个词，用 wordcloud 渲染成 1400×900 的图。

五、这张词云能看出什么

  • “发展”一家独大（350 次），是全文当之无愧的第一热词；紧随其后的”体系、机制、制度、政策、治理”全是框架性词汇。这正是规划文本的文体特征：它不负责描述某个行业怎么做，而是先搭制度框架、定运行机制。
  • “安全”排到第 8（110 次），比”创新”（94）还高。再往下看，”风险”52 次、”监管”46 次也都在前列，与”统筹发展和安全”的定位是对得上的。
  • 科技—产业—数字是一条明确的主线：”创新”94、”产业”78、”科技”59、”数据”47、”人工智能”29、”算力”19。单个看不算顶流，合起来分量很足。
  • 民生侧靠”服务”和”保障”撑起来：”服务”128 次、”保障”100 次，具体落点是”就业”68、”文化”73、”教育”53、”养老”29。
  • 绿色转型的词频不高：”生态”58、”绿色”37。但它单独占了一篇（第十三篇），还带约束性指标（单位 GDP 二氧化碳排放降低 17%、森林覆盖率 25.8%），显然不能只看词频下判断。

需要提醒一句：词频不等于重要性。政策文本里”落实””机制”这类词天然高频，而真正的优先级往往藏在约束性指标、专章篇幅和资金安排里。词云只是入口，判断还得回到原文结构。

六、踩过的坑

  1. 短语被切碎。”新质生产力”会被切成”新质 / 生产力”，”中国式现代化”会被切成”中国式 / 现代化”，只能靠 jieba.add_word() 加词典解决。
  2. 万能动词霸榜。不删”推进、加快、加强、建设、推动”的话，它们能占到前几名，词云上全是大字空话。
  3. 中文变成方块。wordcloud 默认字体不含中文，必须指定 font_path，Windows 下用 simhei.ttf 或 msyh.ttc。
  4. collocations 要关。默认 True 时 wordcloud 会自己再组一遍二元词组，词频就不是我们统计的了。
  5. 目录造成重复计数。文首目录把 18 篇 62 章的标题又数了一遍，”体系””产业”等词会虚高；切掉目录后数据才干净。
  6. 词太多会糊。160 个词在 1400×900 的画布上密度刚好，再往上加小词就开始互相压字。

七、小结

这次实验最大的收获不是词云本身，而是分词前的准备工作：**自定义词典决定短语能不能完整出现，停用词表决定词云里剩下的是”实词”还是”套话”**。同一份文本，停用词表差十个词，出来的图可能完全是两个样子。

另外也确认了一个判断：政策文件的词频结构高度稳定——“发展”永远第一，”体系/机制/制度”永远靠前，具体行业的词反而很难冲进前十。想让词云讲出更多信息，下一步可以按篇、按章分别统计，看每一篇各自的词频差异，那比一张总图有意思得多。
