上一版是”五颗一样大的星、一笔一笔分开画”。这次把三个要求一起解决：颜色做成彩虹渐变、大小做成渐变，并且从第一颗星起笔到最后一颗收笔，中间一次都不抬笔。

一、三个要求分别怎么落地

  1. 彩虹渐变：不手写五个颜色，用 colorsys.hsv_to_rgb 按色相均分。色相从 0 走到 0.72，正好覆盖红、黄、绿、青、蓝紫。
  2. 大小渐变：外接圆半径从 45 递增到 89，每颗加 11，视觉上像一串由小到大的星。
  3. 一笔画：五角星本身就是闭合路径——连走 5 步 144°，合计 720°，正好两整圈，回到起笔的那个顶点。既然最终回到原点，就可以从这里直接”走”向下一颗星的顶点，penup() 全程只调用一次。

二、一笔画的离场点，必须选在顶点

如果图形没有闭合就离开，就会拖出一条从图形中间穿出去的线，非常难看。五角星的 5 次 144° 恰好回到起点，离场点天然落在顶部顶点上，连接线是从顶点往外走，不会破坏图形。

这也是前面那个”转角必须是 144°”的细节为什么重要：它决定了图形能不能干净地闭合。

三、连线：别用直线

两颗星的顶点之间直接拉一条直线，会显得很生硬。这里用二次贝塞尔曲线做了一段轻微上拱的”轨迹线”：

B(t) = (1-t)² P₁ + 2(1-t)t C + t² P₂

控制点 C 取在两点的中点上方 28 像素。贝塞尔曲线在中点只到控制点一半的高度，所以实际上拱大约 14 像素，弧度刚好。线宽 1.4、浅灰色，作为星与星之间的过渡。

一个容易被忽略的点：换颜色、换线宽都不需要抬笔。penup()/pendown() 管的是笔尖离不离开画布，而 color()、pensize() 可以随时改。所以整幅图确实是”一笔”画完的，只是这一笔中途换了五次颜色、两种粗细。

当然，如果非要一张完全没有连接线的图，那就只能抬笔——“一笔画完”和”画面干净”这两件事只能选一个。

六、几个细节

  1. **颜色可以”随走随换”**，只有落不落笔需要 penup()/pendown()。这是 turtle 和不少绘图库不一样的地方。
  2. **每颗星开始前显式 setheading(-72)**。理论上 5 × 144° 是两整圈，朝向会自动转回初值，但连接线是用 goto 画的、不改变朝向，显式设置更不容易出错。
  3. 半径和间距要一起算。五角星的横向宽度约 1.902R，相邻半径差 11、中心间距 170，才刚好留出空隙又不会挤在一起。
  4. **tracer(0) 配 update()**，几百次 goto 瞬间完成，不会看到笔一格一格挪。

八、小结

这次最大的收获是理解”一笔”的真正含义：不是不能停，而是笔尖不离开画布。颜色、粗细、方向都可以在一笔之内变，只有落笔状态不能变。五角星之所以能一笔串起来，是因为它走完五步正好回到起点；换成任何一个不闭合的图形，那条多余的连接线就会从图形中间穿出来。
